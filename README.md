# TN Tool

Extension Chrome tự làm nhiệm vụ ngày, sự kiện và việc lặp lại trong game Tiên Nghịch ([joyplay](https://tiennghich.joyplay.vn), [acejoygame](https://tiennghich.acejoygame.com)). Miễn phí · tác giả [damhieu2808](https://github.com/damhieu2808)

**Cài:** [tải ZIP](https://github.com/damhieu2808/TNTools/archive/refs/heads/main.zip), giải nén, `chrome://extensions` → bật Developer mode → Load unpacked → chọn thư mục `extension`.

Cần cài hộ: liên hệ [TikTok @phuongnguyenconhat](https://www.tiktok.com/@phuongnguyenconhat) · [MIT](LICENSE)
